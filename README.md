# Жукономика — шекельный тайкон

[Играть в браузере](https://mixxxm-bek.github.io/telifon-game/)

Кликай на странных созданий, слушай короткий «Ай» и строй свою шекельную империю.

- Шекели за укусы, комбо, критические и золотые укусы.
- Шесть улучшений: доход за клик, больше созданий, ферма, клешни, комбо и сахарный бонус.
- У каждого жука свой уровень. Эволюция усиливает всю колонию и сохраняет уровни.
- Семь видов: Телифон, Горбатый калоед, Fignya, Притворяшка-вор, Козявка малая, Шекелевый жук и Кусатель вселенной.
- Каждые 67 кликов — 12 секунд SIX SEVEN и двойной доход.
- Автоматическое сохранение в текущем браузере, задания с наградами и доход фермы за время отсутствия.
- Русский интерфейс и адаптивный дизайн для телефона.

Звуки взяты из предоставленных владельцем файлов: «Ай» сокращён примерно до 0,65 секунды, музыкальный фрагмент начинается с 0:01 и длится примерно 12 секунд. Звук и музыку можно выключить отдельно.

Графика, логика и оба аудиофрагмента встроены в `index.html`. Достаточно открыть его в браузере, установка пакетов не нужна. Tab выбирает элемент, Enter активирует укус. Сброс прогресса доступен в настройках с подтверждением.

GitHub Pages публикует ветку `main`, папку `/ (root)`. Файл `.nojekyll` сохраняет обычную статическую публикацию.
