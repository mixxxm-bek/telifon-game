# Телифон кусається

Маленька браузерна гра: натискай на телифонів, вони клацають клешнями, а при укусі звучить «Ай.mp3».

## Грати

Відкрий `index.html` у браузері або опубліковану сторінку GitHub Pages.

- Натисни на телифона, щоб отримати укус.
- «Ще телифона» додає нову істоту.
- «Заново» обнуляє укуси та починає нову гру.
- Кнопка звуку вмикає та вимикає MP3.
- Клавіша Tab вибирає телифона, Enter активує укус.

Гра працює без встановлення пакетів. Звук і графіка вбудовані в `index.html`.

## GitHub Pages

У Settings → Pages вибери Deploy from a branch, гілку `main` і папку `/ (root)`, потім збережи налаштування.

Файл `.nojekyll` дозволяє публікувати гру як звичайну статичну сторінку.
